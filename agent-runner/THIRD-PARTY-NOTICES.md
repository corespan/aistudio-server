## Scope
This file covers the **agent runner** (`agent-runner/`, compose profile `mcp`)
Python dependency tree only. It does **not** cover:

- the server application — see `../THIRD-PARTY-NOTICES.md`;
- the MCP server — see `../mcp-server/THIRD-PARTY-NOTICES.md`;
- the agent-runner image's Debian packages — see `../sbom/`, generated by
  `make sbom-mcp`;
- the LLM it calls and that model's weights: the site supplies both, under
  their own licences (see `../MODEL-LICENSES.md`).

## Redistribution obligations
The packages below carry notice or source-availability obligations that
survive redistribution of a **binary** artifact. If CoreSpan ships a
prebuilt server image, wheel, or installer containing them, the
corresponding licence text must travel with it and, for LGPL, users must
retain the ability to substitute their own build of the library.

### certifi 2026.10.23 — `MPL-2.0`

MPL-2.0 is file-level copyleft. Unmodified, so MPL Section 3.2 is satisfied by shipping the licence text and pointing at the upstream source. Do not patch the bundled CA bundle without re-reading Section 3.3.

### orjson 3.13.0 — `MPL-2.0 AND (Apache-2.0 OR MIT)`

MCP server and agent runner, pulled in by langsmith (via langchain-core). orjson itself is Apache-2.0 OR MIT; the MPL-2.0 part is code it bundles, which ships in the compiled wheel. Unmodified, so as for certifi: MPL Section 3.2 is satisfied by shipping the licence texts the wheel carries (LICENSE-MPL-2.0 among them) and pointing at the upstream source.

### psycopg 3.3.6 — `LGPL-3.0-only`

Agent runner only: the driver LangGraph's Postgres checkpointer requires. LGPL-3.0, used as an unmodified library imported at runtime; same conveyance analysis as paramiko. A user can substitute their own build by installing another psycopg version into the image.

### psycopg-binary 3.3.6 — `LGPL-3.0-only`

Agent runner only. As psycopg2-binary: LGPL-3.0, unmodified; the wheel also embeds libpq (PostgreSQL Licence) and OpenSSL (Apache-2.0 for 3.x).

### psycopg-pool 3.3.3 — `LGPL-3.0-only`

Agent runner only. LGPL-3.0, unmodified, pure Python; same analysis as psycopg.
